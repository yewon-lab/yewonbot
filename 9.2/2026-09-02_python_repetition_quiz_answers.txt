Python 반복문 & 자료구조 기초 정복 테스트 - 답안지 & 해설
============================================================

1. [LEVEL 1]
문제: `for`문의 역할은?
정답: 같은 작업을 여러 번 반복
해설: `for`문은 반복 가능한 데이터를 하나씩 꺼내 같은 작업을 반복할 때 사용합니다.

2. [LEVEL 1]
문제: 다음 코드에서 `number`의 역할은?
정답: 반복할 때마다 값을 받아주는 변수
해설: `number`는 반복할 때마다 `range(3)`에서 나온 값을 하나씩 받아주는 반복 변수입니다.

3. [LEVEL 1]
문제: `i`를 `number`로 바꿔도 될까?
정답: O
해설: 가능합니다. `i`는 특별한 이름이 아니며, 원하는 변수 이름을 사용할 수 있습니다.

4. [LEVEL 1]
문제: `range(5)`가 만들어내는 숫자는?
정답: 0, 1, 2, 3, 4
해설: `range(5)`는 0부터 시작해서 5 직전까지인 0, 1, 2, 3, 4를 만듭니다.

5. [LEVEL 1]
문제: `for i in range(7): print('안녕')`에서 '안녕'은 몇 번 출력될까?
정답: 7번
해설: `range(7)`에는 0~6까지 7개의 값이 있으므로 7번 반복됩니다. `i`에는 0, 1, 2, 3, 4, 5, 6이 들어갑니다.

6. [LEVEL 2]
문제: `for i in range(4): print(i)`의 출력은?
정답: 0, 1, 2, 3
해설: `range(4)`는 0부터 3까지입니다.

7. [LEVEL 2]
문제: `for i in range(2, 7): print(i)`의 출력은?
정답: 2, 3, 4, 5, 6
해설: `range(시작, 끝)`에서 끝값은 포함하지 않습니다. 따라서 2~6입니다.

8. [LEVEL 2]
문제: `range(5, 0, -1)`의 출력은?
정답: 5, 4, 3, 2, 1
해설: 증가폭이 -1이므로 5에서 1까지 내려갑니다. 끝값 0은 포함하지 않습니다.

9. [LEVEL 2]
문제: 5, 4, 3, 2, 1, 0을 출력하려면 `range(5, ???, -1)`의 ???는?
정답: -1
해설: 끝값은 포함되지 않으므로 0까지 포함하려면 끝을 -1로 설정해야 합니다.

10. [LEVEL 3]
문제: [10, 20, 30, 40, 50]에서 30의 인덱스는?
정답: 2
해설: 인덱스는 0부터 시작하므로 10=0, 20=1, 30=2입니다.

11. [LEVEL 3]
문제: `numbers = [10,20,30,40,50]`일 때 `numbers[2]`의 결과는?
정답: 30
해설: 인덱스 2는 세 번째 값인 30을 가리킵니다.

12. [LEVEL 3]
문제: 리스트의 첫 번째 값 10을 가져오는 코드는?
정답: numbers[0]
해설: 리스트 인덱스는 0부터 시작하므로 첫 번째 값은 [0]입니다.

13. [LEVEL 3]
문제: 리스트의 마지막 값 50을 가져오는 코드는?
정답: ①과 ③ 모두 가능
해설: 5개짜리 리스트의 마지막 인덱스는 4이고, 음수 인덱스 -1도 마지막 값을 의미합니다.

14. [LEVEL 3]
문제: `for number in [10,20,30]: print(number)`의 출력은?
정답: 10, 20, 30
해설: 리스트를 직접 반복하면 요소가 하나씩 반복 변수에 들어갑니다.

15. [LEVEL 3]
문제: 위 반복문에서 첫 번째/두 번째/세 번째 반복의 `number` 값은?
정답: 10 → 20 → 30
해설: 첫 번째 요소부터 순서대로 10, 20, 30이 들어갑니다.

16. [LEVEL 4]
문제: `for character in 'ABC': print(character)`의 출력은?
정답: A, B, C가 각각 한 줄
해설: 문자열도 반복 가능한 자료이므로 문자를 하나씩 꺼낼 수 있습니다.

17. [LEVEL 4]
문제: '안녕하세요'는 리스트이기 때문에 for문으로 반복할 수 있다.
정답: X
해설: 문자열은 리스트가 아닙니다. 하지만 문자열도 반복 가능한 자료이므로 for문으로 문자 하나씩 반복할 수 있습니다.

18. [LEVEL 5]
문제: `reversed([10,20,30,40])`를 for문으로 출력하면?
정답: 40,30,20,10
해설: `reversed()`는 반복 가능한 자료를 역순으로 순회하게 해줍니다.

19. [LEVEL 5]
문제: `numbers[::-1]`의 결과는?
정답: [40,30,20,10]
해설: 슬라이싱에서 간격을 -1로 하면 뒤에서부터 전체를 가져옵니다.

20. [LEVEL 5]
문제: `numbers[::-1]`에서 시작, 끝, 간격은?
정답: 시작=자동, 끝=자동, 간격=-1
해설: 시작과 끝을 비워두면 전체 범위를 사용하고, -1 간격으로 역순이 됩니다.

21. [LEVEL 6]
문제: [[1,2,3],[4,5,6],[7,8]]`의 구조는?
정답: 리스트 안에 리스트
해설: 바깥 리스트의 각 요소가 또 하나의 리스트이므로 중첩 리스트입니다.

22. [LEVEL 6]
문제: 첫 번째 for의 `items`에는 무엇이 들어갈까?
정답: [1,2,3] → [4,5,6] → [7,8]
해설: 첫 번째 for는 바깥 리스트의 요소인 '각 안쪽 리스트'를 하나씩 가져옵니다.

23. [LEVEL 6]
문제: `for items in list_of_list: for item in items: print(items)`의 출력은?
정답: 각 안쪽 리스트가 그 안의 요소 수만큼 반복 출력
해설: `print(items)`는 숫자 하나가 아니라 현재의 안쪽 리스트를 출력하므로 각 리스트가 자기 요소 개수만큼 반복됩니다.

24. [LEVEL 6]
문제: 같은 코드에서 `print(item)`으로 바꾸면?
정답: 1,2,3,4,5,6,7,8
해설: 두 번째 for가 안쪽 리스트의 요소를 하나씩 꺼내므로 숫자가 순서대로 출력됩니다.

25. [LEVEL 6]
문제: 중첩 for에서 첫 번째/두 번째 for의 역할은?
정답: 첫 번째=안쪽 리스트, 두 번째=그 리스트 안의 요소
해설: 바깥 for가 안쪽 리스트를 가져오고, 안쪽 for가 그 안쪽 리스트의 요소를 하나씩 가져옵니다.

26. [LEVEL 7]
문제: dictionary에서 Key와 Value의 올바른 짝은?
정답: 위의 세 가지 모두 맞음
해설: 딕셔너리는 Key와 Value를 한 쌍으로 저장합니다.

27. [LEVEL 7]
문제: `dictionary['name']`의 결과는?
정답: 7D 건조 망고
해설: Key 'name'에 연결된 Value를 가져옵니다.

28. [LEVEL 7]
문제: `dictionary['origin']`의 결과는?
정답: 필리핀
해설: Key 'origin'에 연결된 Value는 '필리핀'입니다.

29. [LEVEL 7]
문제: `'age': 20`에서 Key와 Value는?
정답: Key='age', Value=20
해설: 콜론 왼쪽이 Key, 오른쪽이 Value입니다.

30. [LEVEL 7]
문제: 리스트와 딕셔너리는 각각 무엇으로 데이터를 관리할까?
정답: 리스트=인덱스, 딕셔너리=Key
해설: 리스트는 위치를 나타내는 인덱스, 딕셔너리는 Key로 값을 찾습니다.

31. [LEVEL 8]
문제: `person = {'name':'철수'}`에 age 20을 추가하는 코드는?
정답: person['age'] = 20
해설: 새로운 Key에 값을 할당하면 딕셔너리에 데이터가 추가됩니다.

32. [LEVEL 8]
문제: `person['name'] = '영희'` 실행 후 name의 값은?
정답: 영희
해설: 이미 존재하는 Key에 새 값을 할당하면 기존 Value가 수정됩니다.

33. [LEVEL 8]
문제: 딕셔너리에서 age를 삭제하는 방법은?
정답: del person['age']
해설: `del 딕셔너리[Key]` 형태로 해당 항목을 삭제할 수 있습니다.

34. [LEVEL 9]
문제: `'name' in person`의 결과는?
정답: True
해설: 딕셔너리에서 `in`은 기본적으로 Key가 존재하는지 확인합니다.

35. [LEVEL 9]
문제: `'height' in person`의 결과는?
정답: False
해설: person에 height라는 Key가 없으므로 False입니다.

36. [LEVEL 9]
문제: `if key in dictionary:`의 의미는?
정답: Key가 딕셔너리에 존재하는지 확인
해설: `in`은 포함 여부를 확인합니다. 딕셔너리에서는 기본적으로 Key의 존재 여부를 검사합니다.

37. [LEVEL 10]
문제: `for key in dictionary`에서 key에 들어가는 것은?
정답: Key
해설: 딕셔너리를 그대로 for문에 넣으면 Key가 하나씩 반복 변수에 들어갑니다.

38. [LEVEL 10]
문제: 현재 `key = 'name'`일 때 `dictionary[key]`와 같은 코드는?
정답: dictionary["name"]
해설: 변수 key 안에 'name'이 들어 있으므로 dictionary[key]는 dictionary['name']과 같습니다.

39. [LEVEL 10]
문제: `for key in dictionary:`의 `:`와 `print(key, ':', dictionary[key])`의 `':'` 차이는?
정답: 첫 번째는 for문 블록 시작을 나타내고, 두 번째는 출력할 문자열 ':'
해설: 문장 끝의 콜론은 코드 블록 시작을 알리는 문법이고, 따옴표 안의 ':'는 그냥 출력하는 문자열입니다.

40. [FINAL BOSS]
문제: 다음 코드의 최종 목적은?
정답: 딕셔너리의 Key와 그에 해당하는 Value를 함께 출력
해설: for로 Key를 하나씩 꺼내고 dictionary[key]로 그 Key의 Value를 찾아 Key : Value 형태로 출력합니다.

41. [FINAL BOSS]
문제: `ingredient`의 Value는 어떤 자료형인가?
정답: 리스트
해설: ingredient에 연결된 값은 ['망고', '설탕', '치자황색소']이므로 리스트입니다.

42. [BONUS]
문제: `numbers = [15,25,35,45,55]`를 for로 하나씩 출력하려면?
정답: for number in numbers: print(number)
해설: range 없이 리스트 자체를 반복하면 요소가 하나씩 number에 들어갑니다.

43. [BONUS]
문제: 위 리스트를 reversed()로 역순 출력하려면?
정답: for number in reversed(numbers): print(number)
해설: `reversed(numbers)`를 for문에서 순회하면 55부터 15까지 출력됩니다.

44. [BONUS]
문제: person의 Key와 Value를 `name : 철수`처럼 출력하는 가장 적절한 코드는?
정답: for key in person: print(key, ':', person[key])
해설: Key를 반복 변수로 받고 person[key]로 해당 Value를 가져오면 됩니다.
